Under an agent, `/btw <question>` asks a side question: one answer from the context of that session since its last compaction, with no tools, in the sidebar on the right, while the agent keeps working and nothing is written to the session. The panel is a conversation of that session: questions and answers stacked, the input at the bottom, `Clear` to empty it; a question still being answered counts its seconds, the answer streams in as it is written and is formatted as markdown (bold, inline code, lists, headings and code blocks); a picker above the input asks with another model of the session's provider, Haiku or the resident for instance, the session's by default; the panel names the session it is about and opens it on a click, since the sidebar is shared by the workspace, and says which model answered.

How it works: the question returns an id at once (Paseo cuts every plugin RPC at 30 s) and the panel asks for what has arrived every 400 ms. The server locates the agent's transcript through Paseo's Claude providers, builds the request with the transcript since the last compaction and the question, and sends one streamed call with `tools: []` to the local router on `127.0.0.1:18791` with the bearer of the account that owns the session — so it is routed exactly like the session it is asked about, same account, same backend, same quota. The block `You are Claude Code, Anthropic's official CLI for Claude.` is required: without it an OAuth bearer gets 429 from Opus and Sonnet.

Setup: the account store of this machine (`~/.config/claude-cuentas`, or `CLAUDE_CUENTAS_DIR`) must hold the token of the account that owns the session, and the local router must be listening. The plugin only reads: it never writes to the store, to the session or to the transcript.

What it reads and sends: the providers of `~/.paseo/config.json` (`PASEO_HOME`) to find the transcript, the transcript itself, `service.json` + `accounts.json` + `<account>.token` from the account store, and nothing else. The bearer goes only to `127.0.0.1`. It logs nothing: every failure is one of eight fixed texts.

Limits: it needs Paseo 0.11.2 or a later 0.11 release. A session whose context does not fit the model's window is refused with its own text; ask in the conversation instead.
