Under an agent, `/btw <question>` asks a side question: one answer from the context of that session since its last compaction, with no tools, in the sidebar on the right, while the agent keeps working and nothing is written to the session. The panel is a conversation of that session: questions and answers stacked, the input at the bottom, `Clear` to empty it; a question still being answered counts its seconds, the answer streams in as it is written and is formatted as markdown (bold, inline code, lists, headings and code blocks); a picker above the input asks with another model of the session's provider, Haiku or the resident for instance, the session's by default; the panel names the session it is about and opens it on a click, since the sidebar is shared by the workspace, and says which model answered.

How it works: the question returns an id at once (Paseo cuts every plugin RPC at 30 s) and the panel asks for what has arrived every 400 ms. The server locates the agent's transcript through Paseo's Claude providers, builds the request with the transcript since the last compaction and the question, and sends one streamed call with `tools: []` to LiteLLM, at the `ANTHROPIC_BASE_URL` and with the `ANTHROPIC_AUTH_TOKEN` of Paseo's `claude` provider — the same route its sessions take; LiteLLM picks the Claude account. The block `You are Claude Code, Anthropic's official CLI for Claude.` is required: without it an OAuth bearer gets 429 from Opus and Sonnet.

Setup: the `claude` provider of `~/.paseo/config.json` must carry `ANTHROPIC_BASE_URL` (https, or http to loopback) and `ANTHROPIC_AUTH_TOKEN`. The plugin only reads: it never writes to the config, to the session or to the transcript.

What it reads and sends: the providers of `~/.paseo/config.json` (`PASEO_HOME`) to find the transcript, and the LiteLLM route of its `claude` provider, the transcript itself, and nothing else. The key goes only to that LiteLLM. It logs nothing: every failure is one of eight fixed texts.

Limits: it needs Paseo 0.11.2 or a later 0.11 release. A session whose context does not fit the model's window is refused with its own text; ask in the conversation instead.
